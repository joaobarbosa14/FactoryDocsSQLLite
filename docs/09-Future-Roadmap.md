# Future Roadmap

## Phase 1 — MVP
- Document metadata CRUD.
- Search and status.
- SQL Server persistence.
- Angular starter interface.
- VB.NET CSV importer.
- Initial English documentation.

## Phase 2 — DMS Workflow
- Revision table and revision comparison.
- File upload/download with secure storage.
- Approval/rejection workflow.
- Audit history UI.
- Role-based authorization.

## Phase 3 — Enterprise Integration
- Windows Active Directory / Entra ID integration, depending on infrastructure.
- ERP and production-system interfaces.
- Notifications and scheduled jobs.
- Configurable retention policies.
- Centralised logging and monitoring.

## Prioritisation Principles
Prioritise requirements by business value, operational risk, implementation effort and dependency. Validate actual needs with stakeholders before implementing integrations.
